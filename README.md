Basic Computer Skills for Rural School Students
A simple, free website that teaches basic computer skills in 8 levels: Computer Basics, Typing Skills, Files and Folders, MS Word Basics, Internet Basics, Email Basics, Cyber Safety and a Final Challenge.

Features
Home page and 8 learning levels with step-by-step lessons
Typing practice with a 1-minute timer, live word count and accuracy
8 quizzes (10 questions each) with result screen, question review and feedback
XP, badges and a leaderboard for every level
Login / Sign up (saved in the browser) or continue as Guest
Review and feedback page
Works on phones, tablets and computers. No server or database needed.
Files
index.html – page structure
style.css – design and theme
script.js – lessons, quizzes, typing, leaderboard and all features
Publish on GitHub Pages
Create a new repository on GitHub and upload these 4 files.
Go to Settings → Pages.
Under Build and deployment, choose Deploy from a branch, select main and / (root), then Save.
After a minute your site is live at https://<your-username>.github.io/<repository-name>/.
Edit the content
All lessons and quiz questions are in script.js, in the LEVELS list at the top. Typing texts are in PASSAGES.

Note
Progress, accounts and feedback are stored in the visitor's own browser (localStorage), so they are not shared between devices. The leaderboard shows sample students plus the students who used the same device. For a shared online leaderboard, a backend such as Firebase can be added later.
